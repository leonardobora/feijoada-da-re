# Fotos da Feijoada da Rê

O site já tem os espaços reservados para estas fotos. Enquanto o arquivo não existe, o
espaço mostra uma caixa listrada com o nome da foto. Quando você salvar a imagem aqui com
o nome exato da lista, a foto aparece no lugar sozinha, sem mexer no código.

## Como mandar as fotos

1. Salve cada foto nesta pasta (`assets/fotos/`) com o nome exato da tabela abaixo.
2. Formato JPG, deitada quando a tabela pedir, com pelo menos 1200 px no lado maior.
3. Faça o commit e o push. O site atualiza em cerca de 1 minuto.
